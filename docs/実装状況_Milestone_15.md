# v10 実装状況 Milestone 15

作成日: 2026-09-13

## 実装

- v9.7.75の固定commitに含まれるgame.jsから全9章・1,248マスの地形を抽出した。
- 入力をSHA-256で照合し、旧JavaScriptは実行せず配列リテラルだけを解析する。
- 第4章は起動処理に合わせて8行を16行へ展開。第6・7・9章は8×20、その他は8×16。
- Milestone 14で第9章を8×16とした画像metadataの誤りを訂正した。
- 地形定義は各行までimmutableとし、章ごとの地形hashを保存した。
- BattleMapViewをBattleRendererへ接続。既知Stage IDについて章番号・寸法・全地形を確認して背景を描画する。
- 不一致は画面交換の検証段階で拒否し、表示中の戦闘を維持する。
- 背景読み込み成功後にセル背景を透明化する。失敗時は地形色で表示を継続する。
- 再描画で画像を再要求しない。交換・破棄時にlistenerを解除し、旧画像の遅延通知を無効化する。
- GAME_VERSIONは10.0.0-dev.15。Save format 6とcontent revisionは維持。
