# Milestone 21：V9の入口・実際の章・戦闘操作を接続

更新日：2026-09-21。版：10.0.0-dev.21。変更はローカルのみ。

## 最優先の修正方針

ユーザーの指示は「内部構造は変える。プレイヤー側からはほとんど変わっていないようにする」。V9.7.75を実ブラウザーで操作し、V10の英語の開発用戦闘と常設セーブ一覧が通常起動に出ていたことを誤りとして修正した。以前のMilestone文書にある「人物表待ちなので通常画面はfixture」の扱いは、この方針で置き換える。

## 実装

- 固定V9の92人物をデータとして抽出。元ソース全体のハッシュを照合してから、リテラルだけを解析し、旧ゲームコードは実行しない。Excel第4.7版との照合済みとは主張しない。
- 全9章を通常のStageFactory catalogへ登録。406部隊（予備隊含む）、各章の地形・編成・会話・勝敗条件を利用する。
- `StageSelectionScreen` が章一覧、`PlayerShell` がナビゲーション、`Game` が開始・ロード、`BattleSessionHost` が検証後の画面交換を担当する。
- タイトル後に9章の一覧を表示。章の導入会話の後に「作戦条件」を表示し、「戦闘開始」まで盤面をロックする。ロード時には会話・作戦条件を再生しない。
- V9基準の紙色、章ボタン、戦闘概要、上部4ボタン、コマンドドック、円形の駒・向き・兵力バーへ修正。開発情報とセーブ一覧を常設表示から外す。
- 移動プレビューでは駒を移動先に描くが、Domainの位置・行動・乱数は確定まで変更しない。隣接マスで向きを選んで待機。「戻る」で仮移動を取り消す。仮移動中はターン終了不可。
- 敵や行動済みの味方の情報表示、選択部隊の地形・状態・残り回数、日本語のセーブ画面・結果画面を接続。
- 第8章の追捕隊14隊、門路、脱出者2名の保護と南側への脱出条件を接続。語りは架空のCharacterを作らず、Speechの語り手ラベルで表現。
- 第9章の郁保四の第6味方ターンの寝返りと、秦明敗走後の次の味方ターンの4名救援を接続。郁保四が敗走済みなら復活も寝返り会話も発生しない。
- 本来の章と旧fixtureを混ぜてロードしないよう、content revisionを `v10-v9-chapter-catalog-9` へ更新。Save format 6とV10専用prefixは維持。V9の保存領域は操作しない。
- `scripts/serve.mjs` を追加。Windowsの拡張子設定に依存せず、JSを正しいMIMEで配信する。既存PythonサーバーではこのPC上のJSがtext/plainとなり、モジュール起動が止まることを確認した。

## 残るV9との差

この版で全体の同等化を完了したとは扱わない。次は章追加より、以下の画面・操作を優先する。

- 盤面部隊・部隊情報の長押しによる能力詳細の接続。
- 「戦況」を現在の生存部隊一覧から、V9相当の戦闘ログへ接続。
- ステージ情報・戦術指南の表示位置や押下中操作、計略選択の手数などの比較調整。
- 全9章の通しプレイと、勝敗・各イベントを含めた表示比較。自動検証と一部章の実操作を、全章の手動完走の代わりとはしない。

ユーザーのプレイテストや人物表の再提出を作業継続の条件にしない。
