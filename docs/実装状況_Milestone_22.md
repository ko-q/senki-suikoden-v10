# Milestone 22 — 能力詳細・戦況ログ・計略操作のV9同等化

2026-09-21。版は `10.0.0-dev.22`。保存形式6と内容revisionは維持し、M21の保存データも読み込める。

## 実装

- `LongPressGesture` と `UnitDetailView` を追加。盤面部隊・部隊情報を430ms長押しするとV9形式の能力カードを開く。顔、兵力、移動、技能の残回数、向き、地形、四能力、戦闘上の特性、状態異常を表示する。
- 8pxを超えるドラッグで取消。長押し由来のclickを消費し、指を離した直後のclickではカードを閉じない。次のタップで閉じる。Enter/Spaceでも開け、Escapeで閉じる。タイマー、portrait、旧盤面listenerは戦闘の破棄時に解除。
- 移動プレビュー先の地形を表示し、盤面のアクセシビリティラベルも仮移動表示と一致させた。能力を読むだけでは位置・行動・回数・乱数を変更しない。
- `BattleLogRecorder` が確定した処理結果を日本語で記録。手番、攻撃ダメージ、計略成功数と残回数、状態変化、罠、敗走、援軍、寝返り、任務更新、勝敗を扱う。幻術の同士討ちも攻撃として記録。
- 「戦況」を生存部隊一覧から戦闘履歴へ変更。Saveの既存log領域を使用し、読込や再描画では追記しない。演出が失敗しても確定済み戦闘結果は記録される。
- 火計・水計・幻術はコマンドから直接対象選択へ進む。通常の撹乱はレベル選択を残す。取消で消費・Domain・乱数が変わらないことを検証。
- 行動終了後も部隊情報を表示し、行動済み部隊に再度命令できないようにする。盤面の撹乱・幻術の残りターン表示を追加。
- 戦況・ステージ情報・戦術指南をV9相当の上寄せ表示へ変更。背景クリックでも閉じられる。
- V9の戦術指南10項目を移植。承認済みのV10仕様である状態異常の独立保持を記載。未実装のタップ点滅輪の説明は載せない。

- `node --test`：267件すべて成功、約13秒。
- `npm run check` はこの実行環境のPATHにnpmがなく実行できなかったため、package.jsonの同じ2本の `node --check` を直接実行し成功。
- 全9章を公開Controllerコマンドだけで開始から戦闘終了まで自動進行。例外・FAULTED・runtime整合性崩れ・勝敗ログ重複なし。

- 第一章の楊春を仮移動後に攻撃させ、官兵甲への116ダメージ、楊春の東向き・行動済み情報、戦況の1件の攻撃履歴を実画面で確認。
- ブラウザー再読み込み後、自動保存から再開して同じ履歴が重複せず残ることを確認。
- 390×844で戦況、指南、能力画面を確認。能力カード幅358px・高さ約355px、body幅390pxで横はみ出しなし。検証後にviewportをリセット。
