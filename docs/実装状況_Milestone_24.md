# Milestone 24 — 地形説明・戦況の補正・第三章の任務表示

2026-09-21。版は `10.0.0-dev.24`。保存形式6・内容revisionは維持。人物値、編成、戦闘計算式、AIの判断や乱数消費は変更していない。

## 実装

- `TerrainInfoView` に地形説明を分離。森・丘・山岳の防御を「割合と固定値の大きい方」と表示し、丘・山岳の攻撃+3を追加。水系適性では湿地・川の攻防不利なし、山野適性は実際の移動コスト、連環馬は地形別の追加補正を表示する。空きマスでは通常部隊と水系適性の違いを説明する。
- `BattleLogRecorder` が通常攻撃の正面・側面・背面、盾牌、森等の防御、高所攻撃、湿地、連環馬を記録。弓撃・投擲の方向も表示する。向きは確定した攻撃結果に基づき、後で向きが変わっても履歴を変えない。
- 第三章のステージ情報に護送部隊殲滅までの残りターンを表示。任務達成後は固定V9の脱出条件へ切り替え、古い5ターン以内の敗北条件を残さない。セッションのイベント完了状態を読むので、途中のセーブ／ロードにも追従する。
- StageEventの不変データに任意の `logMessages` を追加。Factoryが検証・構築し、Recorderがイベント完了時だけ記録する。第三章の奪取・脱出指示を固定V9から移植。保存は既存の完了イベントIDとログを利用する。
- 脱出旗を文字の旗記号からV9の竿と「脱」の旗に変更。旗は開始時から目印として表示し、脱出条件自体は従来の任務達成判定で有効になる。
- 仮移動の最終区間から表示用の向きを算出し、盤面矢印・部隊情報・能力詳細で共有。「戻る」で元の表示へ戻す。実際のUnitの位置・向き・回数・乱数を仮移動では変更しない。
- `BoardViewportLayout` が固定操作欄の高さを実測し、盤面の上部余白とキーボード移動時のスクロール余白を管理。従来は最上段が操作欄の下に隠れ、上まで戻しても旗に触れなかった。スクロール中の表示位置を補正し、ResizeObserverを戦闘破棄時に解除する。
- 盤面の読み上げ用ラベルを地形キー・英語陣営名から日本語へ変更。
