# Milestone 43 — V9操作を保ったPC入力と仮移動管理の改善

2026-10-24。ユーザーは公開dev.42を「ほぼ同じ」「PCブラウザにも対応」と確認し、さらなる改善を依頼。版は`10.0.0-dev.43`。

## 操作の改善

- Escを既存の「戻る」に接続。通常の選択・仮移動・対象選択・待機方向指定の戻り方を統一。確定済みの計略、演出中、敵ターン、破棄済みの画面では取消しない。
- 押し続けによるキーリピート、文字入力中、IME処理中、修飾キー付き、別の画面で処理済みの入力を除外。
- ステージ情報・戦況・戦術指南と保存枠の画面では、開いたときに閉じるボタンへフォーカスを移す。Tab／Shift+Tabを画面内に保ち、背後の戦闘と章選択をinertにして誤入力を防ぐ。Esc・従来の閉じる操作で元のボタンへ戻す。
- 情報画面から保存枠へ移った後も、閉じたときは元のステージ情報ボタンへ戻す。非表示になった保存ボタンや破棄済みの戦闘画面にはフォーカスを戻さない。
- 情報本文をキーボードで選択可能にし、フォーカスの輪郭とEscの案内を追加。タッチ端末ではPC案内を表示しない。戦況は最新の履歴、指南等は先頭から表示する。

## 内部構造

- `MovePreviewState`は未確定の目的地・候補経路・選択番号だけを所有。経路を複製・凍結し、表示側から候補を書き換えられないようにした。取消時はまとめて破棄する。Unit、Map、乱数を保持・変更しない。
- `BattleKeyboardControls`はキーを既存のコマンドへ接続するだけ。入力受付の判断と行動規則は既存のScreen／Controllerを使用する。
- `ModalFocus`は情報画面のフォーカス循環・復帰・背景入力抑止を担当。以前のinert状態を保持して復元し、終了時にイベントを解除する。
- テンプレート複製直後のDOMは表示先とは別のdocumentを持つ。実ブラウザー確認でこの差によるキー接続漏れを発見し、表示先documentへの接続へ修正。未表示の候補画面・破棄済み画面が入力を受けない回帰テストを追加した。
- 保存形式6、内容revision `v10-v9-chapter-catalog-9`、保存prefixを維持。人物値、章、編成、敵AI、戦闘ルールは変更していない。
