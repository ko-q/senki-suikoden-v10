# Milestone 47 — 部隊詳細の案内と入力制御

2026-10-31。コード版10.0.0-dev.47。第一・二章のV9操作・表示を踏襲するため、部隊詳細への入口と詳細を閉じる操作を改善した。

## 確認した不足と変更

固定V9.7.75では部隊情報に「長押しで詳細」が表示され、詳細には固有人物の異名が表示される。V10はどちらも欠落していた。部隊情報と顔画像はボタンの役割を持つものの、クリックでは開かず、キーボードのリピートを開閉双方で除外していなかった。

- 部隊情報に開き方を表示。PCのクリック・Enter・Space、部隊情報全体の長押しを受け付ける。タブで選ぶ対象も情報全体の1つにまとめ、盤面の長押しは維持。
- 人物データにある異名を詳細の名前の左へ小さく表示。異名なしの場合は表示しない。能力値を追加・変更せず、Excel第4.7版照合済みとは扱わない。
- 詳細を開く許可をBattleRendererの一つの判定へまとめた。手番・入力ロック・詳細表示中・非表示／操作不可の盤面を共通に確認する。
- UnitDetailViewのフォーカス管理と背景入力抑止を既存のModalFocusへ統一。詳細内でTabを保持し、Escで戻る。Enter・Spaceでも閉じられ、繰り返しキーで即座に閉じる／再度開く動作を防ぐ。破棄後に古い画面へフォーカスしない。
- 詳細は仮移動の目的地と向きを表示するが、詳細の開閉だけで仮移動・行動・乱数・履歴を変更しない。
