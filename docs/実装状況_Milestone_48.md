# Milestone 48 — 部隊詳細のスクロールと保存操作の確認

2026-11-03。コード版10.0.0-dev.48。V9の画面と操作を踏襲し、前回残った詳細閲覧と保存操作を改善した。

## 確認した不足と変更

部隊詳細のカードにはoverflowが設定されていたが、背景を止める処理がカード内のwheel／touchmoveも止めていた。低い画面で末尾を読めないため、カード内のスクロールを許可し、カード外だけを抑止した。overscroll-behaviorで背後への連鎖も防ぐ。矢印・PageUp／PageDown・Home／Endでカードをスクロールでき、ドラッグやpointercancel直後のclickで閉じない。名前には既存の人物データにある読み仮名をrubyで表示する。

保存枠の上書き・読込・削除・修復とステージ選択への確認に残っていた標準confirmを、ゲーム内の同じ操作様式へ変更した。空き枠への保存は従来どおり即実行する。

- ActionConfirmationは表示・確認結果・取消・画面破棄を担当し、保存や戦闘の入替えは行わない。既存ModalFocusで戻るへの初期フォーカス、Tab循環、Esc取消、背景入力抑止、元ボタンへの復帰を行う。
- PersistencePanelは確認待ちと操作呼出しを担当する。確認中の追加操作を受け付けず、一覧更新・利用可否の変更・画面破棄で待機を取り消す。遅れて返った結果は操作に使わない。
- Gameは別タブの保存変更通知で確認を閉じ、一覧更新の案内を出す。既存の保存ガードも維持し、確認画面を閉じるだけの保護にはしない。
- Bootstrapは確認画面を注入し、終了時に破棄する。ブラウザー標準confirmに頼らず修復・読込まで動く結合テストを追加。

兵力・マップ・人物能力値・敵AI・戦闘計算・保存形式6・内容revision・保存prefixは変更していない。読み仮名の追加はExcel第4.7版との照合を意味しない。
